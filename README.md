# Neon Forge PC Build Studio

A modern, feature-rich personal PC planning workspace for designing builds, comparing options, tracking orders/returns, and brainstorming ideas—all in a single-page experience with zero external dependencies.

## Running the experience
Open `index.html` in any modern browser. All logic runs client-side.

## Automated tests
Run the headless test suite with Node (no installs required):

```bash
npm test
```

## Features
- Add parts to builds, calculate totals, and watch budget headroom live
- Compare two builds for value, cost deltas, and budget flexibility
- Track orders with inline return handling and live return-rate metrics
- Brainstorm and filter ideas for future iterations
- Responsive glassmorphism-inspired UI tuned for speed and clarity
